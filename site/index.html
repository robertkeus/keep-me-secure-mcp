Questions

What is Keep Me Secure?

Keep Me Secure is a free, open source MCP server. It lets your coding agent check the packages in your project against public security advisories, then answer yes, no or unknown, with what to do next.

Which coding agents does it work with?

It's tested with Claude Code, Codex and opencode. Other agents that support MCP should work too.

Which languages and lockfiles does it support?

PHP (composer.lock), JavaScript (package-lock.json, pnpm-lock.yaml, yarn.lock), Python (requirements.txt, poetry.lock, uv.lock), Go (go.mod), Rust (Cargo.lock), Ruby (Gemfile.lock), Java and Kotlin (gradle.lockfile) and .NET (packages.lock.json).

Where does the security data come from?

OSV.dev for advisories, the CISA Known Exploited Vulnerabilities list for active attacks, and FIRST EPSS for the chance of exploitation.

Is it free? Do I need an account?

Yes, it's free and MIT licensed. You don't need an account or a token.

Will it change my code?

No. It only reads and reports. Your agent suggests the upgrade, and you decide whether to run it.

What does a "no" mean?

No known issue in public advisories at the time of the check. If the check was incomplete, the answer is unknown, never no. It isn't a full security audit: it doesn't cover language runtimes, servers, Docker images or your own code.
